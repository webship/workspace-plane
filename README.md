# @webship.co/workspace-plane

Plane, the open-source project and work management software (Community Edition), for the
[Webship Workspace](https://github.com/webship/workspace) dashboard. It brings a builder that makes a real Plane site in
containers (DDEV by default) from Plane's all-in-one image, with its PostgreSQL, Valkey, RabbitMQ and object store, its
default accounts and a sample workspace and project, the Plane step pack wired into the workspace's testing setup, and
its work items as work items of the tracker family
([`@webship.co/workspace-tracker`](https://github.com/webship/workspace-tracker)): read one, analyze it, and let the
workspace's AI CLI work it on a branch, with a person in charge.

The builder, the provider, the tests and CI come with the first release, `1.0.0`.
